
# the Room Gradation Boundless

**the Room Gradation Boundless**は、**Unity**と**Vket Cloud SDK**を使用して制作した3Dパズル脱出ゲームです。[**株式会社HIKKY**](https://hikky.co.jp/)のプロジェクトとして制作しました。

プレイヤーは、赤・青・緑の3つの部屋にある謎を解き、それぞれの部屋の色を中央の部屋に追加していきます。3つすべての色が中央の部屋に追加され、部屋が白色になると脱出できます。

本作では、通常のUnity開発とは異なり、[**Vket Cloud SDK**](https://vrhikky.github.io/VketCloudSDK_Documents)による制限された開発環境を使用しました。C#ではなく、SDK専用の言語を使用してゲームを実装する必要があり、普段とは異なる開発環境への適応が求められるプロジェクトでした。
